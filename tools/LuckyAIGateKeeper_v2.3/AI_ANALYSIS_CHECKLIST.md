# AI Analysis Checklist

Before answering a complex Lucky AI Solutions request:

- [ ] Read the project context.
- [ ] Identify which project is affected.
- [ ] Identify whether this is strategy, engineering, research, business,
      or implementation.
- [ ] Separate facts from assumptions.
- [ ] Decompose futuristic claims into primitives.
- [ ] Identify the actual constraint.
- [ ] Check whether current technology already solves part of it.
- [ ] Identify what can be done now.
- [ ] Identify what needs integration.
- [ ] Identify what is only simulated.
- [ ] Identify what would make the simulation real.
- [ ] Define a measurable experiment.
- [ ] Define a failure condition.
- [ ] Avoid unsupported certainty.
- [ ] Preserve user intent while correcting factual errors.
