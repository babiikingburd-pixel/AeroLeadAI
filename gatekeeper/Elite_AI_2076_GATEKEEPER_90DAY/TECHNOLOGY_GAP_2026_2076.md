# Technology Gap Map

## Build immediately with existing technology

- Multimodal AI
- Computer vision
- Temporal image comparison
- Digital twins
- LiDAR processing
- SAR integration
- Thermal analysis
- Weather/storm modeling
- Agent orchestration
- Evidence provenance
- Predictive models
- Outcome learning

## Build interfaces now for technologies that will mature

- Continuous Earth observation
- Autonomous drones
- Connected building sensors
- Physical-world foundation models
- Advanced spatial AI
- Autonomous trade coordination
- General physical-world reasoning
- Continuous property forecasting

## Strategic principle

Never make a future dependency a prerequisite for today's product.

Instead:

1. Define the future capability.
2. Define its required data contract.
3. Build the interface.
4. Build today's best implementation behind the interface.
5. Replace the implementation as better technology arrives.

This makes AeroLeadAI evolution-compatible.
