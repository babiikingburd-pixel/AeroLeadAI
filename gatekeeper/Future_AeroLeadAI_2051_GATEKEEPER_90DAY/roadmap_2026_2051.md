# AeroLeadAI 2026-2051 Roadmap

## Phase 1 — 2026-2030
Build the foundation.
- Normalize property records.
- Make apex_evidence_events a durable evidence layer.
- Build property digital twins.
- Add temporal imagery/change detection.
- Build Top-500 continuous investigation.
- Track confidence and evidence freshness.
- Separate observation, prediction and action.

## Phase 2 — 2030-2040
Build predictive property intelligence.
- Multi-agent investigation.
- 3D/LiDAR property reconstruction.
- More sophisticated storm/physics models.
- Predictive maintenance.
- Contractor matching.
- Closed-loop outcome learning.
- Dial-A-Trade operational integration.

## Phase 3 — 2040-2051
Build the physical-world intelligence layer.
- Continuous or near-continuous observation.
- Autonomous inspection.
- Building sensor integration.
- Spatial/AR interfaces.
- Physical-world foundation models.
- Autonomous scheduling and field coordination.
- Property-level forecasting across multiple trades.

## North-star question

Do not ask only:
"Is this a lead?"

Ask:
"What is happening to this property, what is likely to happen next, when will it happen, what will it cost, and who should act?"
